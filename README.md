# A lib for monitoring usage of CPUs and GPUs


### Some other commands to check CPUs:
  
    lscpu 
    nano /proc/cpuinfo
    nproc
    getconf _NPROCESSORS_ONLN

### Open soft:

    hwinfo 
    hwinfo --cpu
